# Fase 4: Prueba de Concepto en Python (Notebook)

En esta carpeta se alojará el cuaderno ejecutable de Google Colab (`.ipynb`) que valida el cálculo computacional del **Índice de Preparación Previa (IPP)**.

## Contenido planificado:
1. **Carga y descripción del dataset:** Uso de dataset público OULAD (`studentAssessment` y `studentVle`).
2. **Limpieza y transformación:** Construcción del IPP a partir de marcas temporales de acceso a recursos previas a la entrega.
3. **Visualización tipo tablero:** Gráfico interactivo (Plotly / Dash) simulando la vista del semáforo docente o la barra del estudiante.
4. **Modelo base:** Regresión logística o árbol de decisión para predecir la entrega a tiempo según el IPP.
5. **Sección reflexiva:** «Lo que este prototipo no puede decir todavía».
