# Fase 2: Diccionario de Datos y Consideraciones Eticas

Esta carpeta contiene la especificacion formal de los datos que utiliza la herramienta **CheckBefore**, incluyendo el diccionario de variables, el flujo de procesamiento, el mapeo al dataset OULAD para la prueba de concepto y el marco etico de privacidad y control de sesgos.

## Contenido

- [diccionario_datos_y_etica.md](diccionario_datos_y_etica.md) - Documento principal con:
  1. Diccionario de variables de origen (13 variables extraidas de Moodle).
  2. Variables derivadas e indicadores calculados (7 indicadores, incluyendo el IPP y el semaforo de riesgo).
  3. Tabla de mapeo CheckBefore - OULAD para la prueba de concepto.
  4. Flujo de procesamiento de datos (5 pasos: extraccion, filtrado temporal, calculo, clasificacion, presentacion).
  5. Consideraciones eticas: principios rectores, anonimizacion, matriz de permisos de acceso por rol, consentimiento informado y analisis de 5 sesgos potenciales con sus estrategias de mitigacion.
  6. Limitaciones conocidas del modelo de datos.
