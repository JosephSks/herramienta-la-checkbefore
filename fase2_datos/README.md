# Fase 2: Los Datos y Consideraciones Éticas

En esta carpeta se desarrollará el **Hito 2 (Fin de semana 2)** correspondiente a la especificación de datos de la herramienta **CheckBefore**.

## Contenido planificado:
1. **Diccionario de Datos:**
   - Tabla con cada variable requerida de Moodle / SGA.
   - Especificación de: Fuente institucional, Tipo de dato, Granularidad, Frecuencia de actualización y Fórmula de transformación a indicador.
2. **Sección de Ética y Privacidad:**
   - Detalle de anonimización de identificadores.
   - Matriz de permisos de acceso (quién ve qué información).
   - Mecanismos de consentimiento informado en eVirtual.
   - Análisis y mitigación de sesgos algorítmicos.
